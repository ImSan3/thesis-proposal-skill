## 1. 项目介绍

### 1.1 这是什么

`thesis-proposal` 是一个专为中国本科毕业论文**开题报告**设计的 AI 技能。它将开题报告的撰写过程拆解为标准化的工程流程：

> **采集输入 → 参考文献分类 → 重编号 → 撰写研究现状 → 填充模板 → 输出文档**

整个过程交互式进行，每个关键步骤都会展示给用户确认，确保输出质量可控。

### 1.2 解决什么问题

| 痛点 | 解决方案 |
|------|---------|
| 开题报告结构复杂，不知从何下手 | 标准化模板 + 自动填充 |
| 参考文献分类耗时 | 智能分类（国内3类 + 国外2类） |
| 文献序号被打乱 | 自动重编号，顺序不变 |
| 学者观点撰写困难 | 按主题综合多位学者观点，并在连贯段落中逐条标注文献 |
| 格式调整繁琐 | 自动适配学校模板格式 |

### 1.3 设计哲学

- **交互优先**：每个步骤都展示给用户确认，避免返工
- **分类驱动**：文献先分类再撰写，确保研究现状结构清晰
- **模板适配**：支持自定义模板，自动填充对应区域
- **零门槛**：只需提供题目和文献，无需了解排版格式

## 3. 工作流程

### 3.1 文献分类规则

**国内文献分为 3 类**（示例）：

| 类别 | 主题 | 说明 |
|------|------|------|
| 第一类 | 养老金融与养老保障体系建设 | 制度设计、体系构建、政策框架 |
| 第二类 | 养老保险制度运行与参保现状 | 参保覆盖、制度执行、转移接续 |
| 第三类 | 养老保险基金可持续性与监管 | 基金收支、投资运营、监管机制 |

**国外文献分为 2 类**（示例）：

| 类别 | 主题 | 说明 |
|------|------|------|
| 第一类 | 国外养老保险制度改革与评估 | 改革实践、制度评估 |
| 第二类 | 国外养老保险基金可持续性与风险管理 | 可持续性分析、风险防控 |

### 3.2 引用格式规范

学者观点引用格式：

```
学者姓名（年份）认为xxxxx[序号]。
```

示例：
> 吴怀军（2025）从数字技术应用角度讨论养老金融服务，强调信息技术有助于扩大服务覆盖面[1]；李明（2024）则关注风险识别机制，指出数据整合可提升决策的及时性[2]。两项研究分别从服务供给和风险管理切入，体现了数字化转型的不同作用路径。

## 4. 快速开始

安装完成后，直接把题目和文献交给 Agent：

| 想做什么 | 直接这样说 |
|---------|-----------|
| 生成开题报告 | `帮我写一个开题报告，题目是XXX，研究内容是XXX，参考文献如下...` |
| 只做研究现状 | `先帮我分类这些参考文献，然后撰写国内外研究现状` |
| 填充模板 | `我已经有了研究现状内容，请帮我填充到开题报告模板中` |

## 5. 安装

### 5.1 Hermes Agent 安装方式

```bash
# 克隆仓库
git clone https://github.com/SannotTired/thesis-proposal-skill.git

# 将技能目录复制到 Hermes 技能目录
cp -r thesis-proposal-skill/skills/thesis-proposal ~/.hermes/skills/thesis-proposal
```

### 5.2 Codex 安装方式

```bash
# 使用 npx skills 安装
npx skills add SannotTired/thesis-proposal-skill --agent codex --skill thesis-proposal --yes --copy
```
