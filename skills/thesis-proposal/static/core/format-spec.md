# 格式规范

## 引用格式

学者观点引用格式：

```
学者A（年份）从……角度提出……[序号]；学者B（年份）进一步指出……[序号]。两项研究分别……。
```

角标 `[序号]` 必须紧贴在句号前面。

## 字数要求

| 区域 | 字数 |
|------|------|
| 研究目的 | ~300字 |
| 研究意义 | ~500字 |
| 新颖性 | ~250字 |
| 学者观点 | 按主题综合写作，段落数量依类别和子议题确定；不要求每篇文献单独成段 |
| 宏观概括 | ~150字 |

## 参考文献格式

遵循 GB/T 7714-2015 格式。

## 模板格式

- 正文：宋体小四(12pt)，两端对齐，首行缩进2字符，1.25倍行距
- 一级标题：黑体三号(16pt)居中
- 二级标题：黑体四号(14pt)左对齐
- 参考文献：五号宋体(10.5pt)
