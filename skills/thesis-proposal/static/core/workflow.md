# 核心工作流程

## Step 1: 信息采集

交互式采集以下信息：

```python
title = input("论文题目: ")
research_content = input("主要研究内容: ")
domestic_refs = input("国内参考文献(每行一条，空行结束): ")
foreign_refs = input("国外参考文献(每行一条，空行结束): ")
```

## Step 2: 国内外研究现状工程

### 2.1 参考文献分类

- 国内文献 → 3类（按主题）
- 国外文献 → 2类（按主题）
- 每条文献只归入一个类别
- 展示分类结果给用户确认

### 2.2 重新排序编号

- 分类结构和文献上下顺序不动
- 序号改为连续递增（1, 2, 3...）
- 展示重编号结果给用户确认

### 2.3 撰写文章内容

- 国内研究现状：宏观概括 + 3类分段
- 国外研究现状：宏观概括 + 2类分段
- 文献综述：价值 + 不足 + 引出
- 按主题综合多位学者观点，以一个或少量连贯段落呈现；每篇文献均需在对应观点处引用，但不按每篇文献单独分段

## Step 3: 填充模板

按模板结构逐项填充所有区域。

## Step 4: 输出与验证

生成 .docx 后验证完整性和引用准确性。
