# 开题报告生成技能（Thesis Proposal Generator）

## 一、概述

本技能为中国本科毕业论文生成完整的**开题报告（研究方案）**Word 文档。

开题报告是本科毕业论文答辩前的关键文档，需要完整覆盖：研究目的与意义、国内外研究现状、拟研究问题、新颖性、研究方法、论文大纲、参考文献及进度安排。

**核心工作流**：

```
用户提供题目 + 研究内容 + 国内参考文献 + 国外参考文献
        ↓
执行「国内外研究现状工程」（分类 → 重编号 → 撰写）
        ↓
按模板结构逐项填充内容
        ↓
输出 .docx 并验证
```

**模板位置**：`~/Desktop/开题报告模板.docx`

## 二、适用场景（触发条件）

### 触发关键词
- 「写开题报告」「生成开题报告」「做开题报告」「开题报告模板」
- 「研究方案」「选题报告」「论文计划书」
- 「thesis proposal」「research proposal」

### 适用条件
- 用户提供了论文题目、主要研究内容、国内参考文献（≥8 条）、国外参考文献（≥3 条）
- 学科为本科层级（非硕博）

### 不适用场景
- 正式论文正文（应使用 `academic-coursework` 技能）
- 答辩 PPT
- 文献综述单独生成

## 三、核心工作流程

### 步骤一：交互式信息采集

**必须使用交互式输入，禁止硬编码或假设用户意图。**

向用户采集以下信息：

| 采集项 | 要求 | 最低数量 |
|--------|------|----------|
| 论文题目 | 精确的论文选题名称 | 1 个 |
| 主要研究内容 | 章节框架 / 研究思路 / 核心问题 | 必填 |
| 国内参考文献 | GB/T 7714 格式，含作者、年份、标题、期刊/出版信息 | ≥8 条 |
| 国外参考文献 | 标准引用格式，含作者、年份、标题、期刊/出版信息 | ≥3 条 |

**完成标准**：
1. 所有信息已获取
2. 向用户展示采集结果摘要，请求确认
3. 用户确认无误后进入步骤二

---

### 步骤二：国内外研究现状工程

这是本技能的**核心环节**。严格按以下三个子步骤执行，每个子步骤完成后均需向用户展示结果并获得确认。

#### 子步骤一：参考文献分类

将国内文献分为 **3 个类别**，国外文献分为 **2 个类别**。

**国内文献分类原则**（三选三）：
1. 按研究主题 / 研究角度划分
2. 每条文献只能归入一个类别，**不得重叠**
3. 每个类别以 `关于xxxx方面的研究` 命名
4. 每类下方列出该类包含的所有文献

**国外文献分类原则**（二选二）：
1. 按研究主题 / 研究范式划分
2. 每条文献只能归入一个类别，**不得重叠**
3. 每个类别以英文或中英文混合命名
4. 每类下方列出该类包含的所有文献

**输出格式**：

```
国内文献共 X 篇，分为 3 类：

（一）关于xxxx方面的研究
[1] 作者. 标题[J]. 期刊, 年份, 卷(期): 页码.
[2] ...

（二）关于yyyy方面的研究
[3] ...

（三）关于zzzz方面的研究
[5] ...

国外文献共 Y 篇，分为 2 类：

（一）xxxx方面的研究
[N] ...

（二）yyyy方面的研究
[N+1] ...
```

展示给用户确认分类是否合理。若用户提出异议，调整后重新展示。

#### 子步骤二：重新排序编号

在分类结构和文献上下顺序**完全不动**的前提下，将序号改为连续递增（1, 2, 3, 4, 5 ...）。

**操作规则**：
- 只改序号，文献内容、分类标题、文献排列顺序均不变
- 国内文献从 1 开始连续编号
- 国外文献紧接国内文献之后继续编号

**输出格式**：

```
国内文献（共 X 篇）：

（一）关于xxxx方面的研究
[1] 作者. 标题[J]. 期刊, 年份, 卷(期): 页码.
[2] ...

（二）关于yyyy方面的研究
[3] ...

（三）关于zzzz方面的研究
[5] ...

国外文献（共 Y 篇）：

（一）xxxx方面的研究
[X+1] ...

（二）yyyy方面的研究
[X+3] ...
```

展示给用户确认。确保与子步骤一的分类完全一致，仅序号发生变化。

#### 子步骤三：撰写研究现状内容

基于重编号后的分类文献，撰写三个板块的内容。

##### 2.1 国内研究现状

1. **宏观概括段**（约 150 字）：对国内整体研究情况进行概括性描述
2. **分类段落**：按类别分段，每段以 `关于xxxx方面的研究，` 开头
3. **学者观点**：每篇文献对应一个学者观点段落（约 120 字）
4. **引用格式**：`学者姓名（年份）认为xxxxx[序号]。`

##### 2.2 国外研究现状

结构与国内研究现状完全一致：
1. 宏观概括段（约 100 字）
2. 按类别分段
3. 每篇文献对应学者观点
4. 引用格式同上

##### 2.3 文献综合述评

撰写三层递进式述评：
1. **价值肯定**：现有研究在XX方面积累了丰富成果，为本文提供了重要参考
2. **不足指出**：现有研究存在1-2点不足（如对XX关注不够、缺少XX方面的实证等）
3. **引出必要**：因此本文从XX角度切入，具有理论和实践价值

**完成标准**：
- 每篇文献均被引用，无遗漏
- 国内研究现状 + 国外研究现状的文献总数 = 参考文献总数
- 每篇文献都有对应的学者观点段落

---

### 步骤三：填充开题报告模板

按模板结构逐项填充，各板块内容要求如下：

| 板块 | 字数要求 | 内容说明 |
|------|----------|----------|
| **研究目的** | ~300 字 | 阐述研究该题目的现实背景和研究目的，说明预期解决的问题 |
| **研究意义** | ~500 字 | 分理论意义和实践意义两方面阐述，说明对现实有何作用、理论上有什么价值 |
| **国内研究现状** | 按实际 | 步骤二子步骤三中生成的 2.1 全部内容 |
| **国外研究现状** | 按实际 | 步骤二子步骤三中生成的 2.2 全部内容 |
| **文献综合述评** | 按实际 | 步骤二子步骤三中生成的 2.3 全部内容 |
| **拟研究的主要问题** | ~250 字 | 列出 3 个主要问题，分条列举并简要展开，宏观概括以保持灵活性 |
| **新颖性** | ~250 字 | 一段连贯语言，阐述选题创新或研究方法创新之处 |
| **拟采用的研究方法** | ~250 字 | 2-3 个方法，**文献研究法为必备项**，方法需实事求是 |
| **论文大纲** | 按实际 | 按用户提供的章节结构，层次分明（1、1.1、1.1.1 等） |
| **主要参考文献** | 全部 | 步骤二子步骤二中重排序后的完整文献列表 |
| **整体进度安排** | 按实际 | 按月排列，覆盖开题到答辩全过程 |

**论文大纲标准结构参考**：

```
1 绪论
  1.1 研究背景与意义
    1.1.1 研究背景
    1.1.2 研究意义
  1.2 文献综述
    1.2.1 国内研究现状
    1.2.2 国外研究现状
    1.2.3 文献综合述评
  1.3 研究内容与方法
    1.3.1 研究内容
    1.3.2 研究方法
2 ...（后续章节根据用户研究内容确定）
...
N 结论
参考文献
致谢
```

**整体进度安排参考格式**：

```
2025.01-2025.02  查阅文献，确定选题，撰写开题报告
2025.03-2025.04  深入研究，收集数据/资料，完成初稿
2025.05          修改论文，定稿，准备答辩材料
2025.05-2025.06  论文答辩
```

---

### 步骤四：输出与验证

使用 `python-docx` 库将填充好的内容写入 `.docx` 文件，并执行以下验证：

1. **板块完整性**：模板所有区域（研究目的、研究意义、国内外研究现状、文献综合述评、拟研究问题、新颖性、研究方法、论文大纲、参考文献、进度安排）均已填充
2. **文献无遗漏**：参考文献数量 = 分类工程中的文献总数
3. **学者观点无遗漏**：每篇文献都有对应的学者观点段落
4. **序号连续性**：参考文献序号从 1 开始连续递增，无跳号
5. **引用格式正确**：全部符合 `学者姓名（年份）认为xxxxx[序号]。` 格式
6. **文献综合述评完整**：包含价值肯定 + 不足指出 + 引出必要三层
7. **研究方法包含文献研究法**：2-3 个方法中必须包含文献研究法
8. **文件保存**：.docx 已保存至用户指定路径

## 四、内容撰写指南

### 学者观点撰写规范

每篇文献对应一个学者观点段落，约 **120 字**。格式：

```
学者姓名（年份）认为xxxxx[序号]。
```

**撰写要求**：
- 开头必须是 `学者姓名（年份）`
- 结尾必须是 `[序号]。`（方括号紧贴句号前）
- 中间内容需围绕文献标题 + 论文主题，阐述学者的核心观点或研究发现
- 每段一个学者观点，不合并多篇文献

**示例**：

> 吴怀军（2025）结合江苏省实际情况，探讨了数字经济赋能养老金融的可行路径，认为信息技术手段能够有效提升养老金融服务的覆盖面与精准度，为养老保险制度的数字化转型提供了实践参考[1]。

### 宏观概括段撰写规范

**国内研究现状宏观概括**（约 150 字）：
- 概括国内学者在该领域的整体研究趋势
- 提及研究的主要方向和热点
- 为后续分类段落做铺垫

**国外研究现状宏观概括**（约 100 字）：
- 概括国外学者的研究特点
- 与国内研究形成对照
- 引出分类段落

### 分类段落撰写规范

每段以 `关于xxxx方面的研究，` 开头，然后依次列出该类别下的学者观点：

```
关于xxxx方面的研究，
学者A（年份）认为……[序号]。
学者B（年份）认为……[序号]。
学者C（年份）认为……[序号]。
```

### 文献综述撰写规范

文献综述需包含**三层递进**：

1. **价值肯定**（1-2 句）：
   - 「综上所述，国内外学者在XX方面进行了大量研究，积累了丰富的理论成果和实践经验，为本文的研究提供了重要参考。」

2. **不足指出**（1-2 点）：
   - 现有研究对XX关注不足
   - 针对XX行业的实证研究较少
   - 缺少XX角度的分析
   - 研究方法较为单一

3. **引出必要**（1-2 句）：
   - 「因此，本文拟从XX角度切入，针对XX问题展开深入研究，具有一定的理论价值和现实意义。」

### 研究目的撰写规范

约 **300 字**，结构：

```
首先，阐述研究的现实背景（社会现象/行业问题/政策需求）。
其次，说明研究该题目的具体目的。
最后，概括预期解决的核心问题。
```

### 研究意义撰写规范

约 **500 字**，分两部分：

1. **理论意义**（~200 字）：
   - 丰富XX领域的理论研究
   - 为XX理论提供新的实证支持
   - 拓展XX的研究视角

2. **实践意义**（~300 字）：
   - 为XX提供决策参考
   - 为XX行业提供实践指导
   - 推动XX的优化与发展

### 新颖性撰写规范

约 **250 字**，一段连贯语言：

```
本选题的新颖性主要体现在以下几个方面：
第一，研究视角创新……
第二，研究方法创新……
第三，研究内容创新……
```

或用一段话连贯表达，突出 1-2 个创新点即可。

### 研究方法撰写规范

约 **250 字**，2-3 个方法：

- **文献研究法**（必备）：通过查阅国内外相关文献，梳理研究现状，为本研究提供理论基础。
- 根据实际需要选择：问卷调查法、访谈法、案例分析法、比较分析法、实证分析法等。
- 每个方法需说明具体用途，实事求是，不夸大。

## 五、常见陷阱

| 序号 | 陷阱 | 说明 | 防范措施 |
|------|------|------|----------|
| 1 | 文献遗漏 | 用户给多少篇参考文献，学者观点就必须写多少条 | 完成后逐一核对文献编号 |
| 2 | 分类重叠 | 同一文献归入两个类别 | 每条文献只能出现一次 |
| 3 | 序号错乱 | 重编号时文献内容或顺序发生变化 | 只改序号，其余不动 |
| 4 | 研究现状与文献脱节 | 学者观点与文献标题/论文主题无关 | 撰写前先分析文献标题关键词 |
| 5 | 引用格式错误 | 使用 `学者姓名[序号]` 而非 `学者姓名（年份）` | 严格按模板格式 |
| 6 | 角标位置错误 | `[序号]` 放在句号后面 | `[序号]` 必须紧贴句号前，如 `...观点内容[1]。` |
| 7 | 文献综述缺层 | 只写肯定或只写不足 | 确保三层递进完整 |
| 8 | 研究方法缺少文献研究法 | 只写了其他方法 | 文献研究法为必备项 |
| 9 | 字数不达标 | 研究目的不足300字、研究意义不足500字 | 逐板块检查字数 |
| 10 | 模板板块遗漏 | 忘记填充某个板块 | 按模板结构逐一核对 |

## 六、验证清单

在输出 .docx 之前，逐项检查以下清单：

### 输入验证
- [ ] 论文题目已获取
- [ ] 主要研究内容已获取
- [ ] 国内参考文献 ≥8 条
- [ ] 国外参考文献 ≥3 条
- [ ] 用户已确认采集结果

### 分类验证
- [ ] 国内文献分为 3 类，每类有明确标题
- [ ] 国外文献分为 2 类，每类有明确标题
- [ ] 每条文献仅归入一个类别，无重叠
- [ ] 用户已确认分类结果

### 重编号验证
- [ ] 序号从 1 开始连续递增
- [ ] 文献内容与分类结构未发生变化
- [ ] 用户已确认重编号结果

### 内容验证
- [ ] 国内研究现状：宏观概括 + 3 类分段 + 每篇文献有学者观点
- [ ] 国外研究现状：宏观概括 + 2 类分段 + 每篇文献有学者观点
- [ ] 文献综述：有价值肯定 + 有不足指出 + 有引出必要
- [ ] 研究目的约 300 字
- [ ] 研究意义约 500 字
- [ ] 新颖性约 250 字
- [ ] 研究方法 2-3 个且包含文献研究法
- [ ] 拟研究问题 3 个，宏观概括

### 引用验证
- [ ] 每篇文献都有对应的学者观点段落
- [ ] 学者观点数量 = 参考文献总数
- [ ] 引用格式统一为 `学者姓名（年份）认为xxxxx[序号]。`
- [ ] `[序号]` 紧贴句号前，如 `...观点内容[1]。`

### 输出验证
- [ ] .docx 文件已保存
- [ ] 模板所有板块均已填充
- [ ] 参考文献列表完整（重编号后）
- [ ] 进度安排覆盖开题到答辩
