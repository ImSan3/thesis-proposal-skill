# `thesis-proposal` 技能

`thesis-proposal` 用于自动生成中国本科毕业论文的开题报告（研究方案），输出为符合学校模板的 `.docx` 文件。

## 适合用它做什么

- 根据论文题目和参考文献，自动生成完整开题报告
- 对国内外参考文献进行智能分类（国内3类 + 国外2类）
- 自动重编号参考文献，保持顺序连续递增
- 为每篇文献撰写约120字的学者观点段落
- 自动填充学校模板的所有区域（研究目的、意义、现状、问题、方法、大纲等）

## 典型请求

- "帮我写一个开题报告，题目是《江苏省基本养老保险发展问题研究》"
- "先帮我分类这些参考文献，然后撰写国内外研究现状"
- "我已经有了研究现状内容，请帮我填充到开题报告模板中"

## 你需要提供

- 论文题目
- 主要研究内容（章节框架或研究思路）
- 国内参考文献（≥8条）
- 国外参考文献（≥3条）

## 产出

- 完整的开题报告 `.docx` 文件
- 包含：研究目的、研究意义、国内外研究现状、文献综述、主要问题、新颖性、研究方法、论文大纲、参考文献、进度安排

## 工作流程

```
题目 + 内容 + 文献
       ↓
  文献分类（国内3类 + 国外2类）
       ↓
  重新编号（序号连续递增）
       ↓
  撰写研究现状（每篇文献~120字）
       ↓
  填充模板（所有区域）
       ↓
  输出 .docx + 验证
```

## 边界

- 不会替用户虚构参考文献
- 不处理正式论文正文（使用 `academic-coursework`）
- 不生成答辩PPT（使用 `academic-presentation`）

## 相关技能

- `docx-formatting`: python-docx 格式化、三线表、标题层级
- `academic-coursework`: 学术论文写作全流程
- `academic-presentation`: 答辩PPT生成
