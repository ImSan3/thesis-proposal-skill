# thesis-companion

面向中文开题报告和毕业论文的解读与答辩准备技能。上传报告或论文后，可生成三份配套 DOCX：

1. 带真实 Word 批注的讲解版，解释研究逻辑、技术难点和文中指标。
2. 帮助学生快速读懂全文的速读指南。
3. 针对论文内容预测导师可能提出的问题，并提供学生口吻的回答。

默认排版为中文宋体四号、英文和数字 Times New Roman 四号、1.5 倍行距。讲解以解释论文为主，不输出错误点评或纠错报告。开题报告按计划和预期表述，不虚构研究发现。

三份文档完成后，技能会询问是否需要额外制作答辩 PPT。只有用户明确需要时才制作，并使用蓝白学术风格；若生成 PPT，同时提供约 2000 字、约十分钟的逐字稿 DOCX，并将逐页讲稿放入对应幻灯片备注。

## 安装

将本目录复制到 Codex 的 skills 目录，或使用兼容 Agent 的技能安装器从本仓库安装 `thesis-companion`。

## 文件

- `SKILL.md`：技能入口与工作流。
- `references/`：交付、指标解释、Word 批注、答辩问答和 PPT 规范。
- `agents/openai.yaml`：Codex 界面元数据。
